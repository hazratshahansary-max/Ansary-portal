ANSARY KNOWLEDGE – ګډه نسخه د Cloudflare Pages لپاره

په دې نسخه کې د اصلي ANSARY KNOWLEDGE ټولې برخې ساتل شوې دي، او د AI پرامپټونو، ګټورو لینکونو، خوښې وړ توکو او د هغوی ځانګړی اډمین مدیریت هم ورزیات شوی دی.

د ویب‌سایټ پاڼې:
- اصلي وېب‌سایټ: /
- AI پرامپټونه او ګټور لینکونه: /resources.html

د اصلي وېب‌سایټ په Header کې د «AI پرامپټونه او ګټور لینکونه» تڼۍ شته. د سرچینو په پاڼه کې د اصلي وېب‌سایټ ته د بېرته تګ لینک شته.

Cloudflare Pages Build Settings:
Framework preset: None
Build command: npm run build
Build output directory: dist  (ټول توري کوچني)
Root directory: /

مهم:
1. د GitHub اوسنی Repository لومړی Backup کړه؛ زاړه فایلونه تر Backup پرته مه ړنګوه.
2. د دې فولډر ټول فایلونه د GitHub Repository اصلي (root) ځای ته پورته کړه او Commit یې کړه.
3. Cloudflare به د GitHub د main څانګې له تازه Commit څخه نوی Deployment جوړ کړي.
4. د اصلي ویب‌سایټ او /resources.html دواړه پاڼې جلا جلا وازمویه.

د AI پرامپټونو او ګټورو لینکونو اډمین لاګین د Supabase Auth او د مدیر د رول تایید ته اړتیا لري. که د Supabase اړوند Environment Variables او Database/RLS تنظیمات برابر نه وي، د اډمین ننوتل او آنلاین همغږي به کار ونه کړي. د اصلي ویب‌سایټ د محتوا اډمین جلا برخه ده.

دا نسخه د دواړو پروژو د جلا ساتلو له لارې یوځای شوې ده: اصلي علمي/کتابتون ویب‌سایټ په index.html کې، او د AI پرامپټونو/لینکونو ماډیول په resources.html کې. د دواړو برخو localStorage ډاټا او اډمین جریانونه جلا دي.
